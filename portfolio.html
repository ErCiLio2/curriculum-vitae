SOMATEC · Em produção

Troco Seguro — Fintech e Mobilidade
NestJS 11ReactVitePostgreSQLRedisMinIOFirebaseDockerWhatsApp API
Em produção · Angola

Plataforma completa de pagamentos e gestão de frotas de transporte para Angola. Três superfícies: app mobile (motorista e passageiro), painel web (admin + gestor de frota) e API pública Troco Pay para integrações externas.

Funcionalidades chave

  • Pagamentos por QR code em dois sentidos: passageiro escaneia motorista e motorista escaneia cartão virtual do passageiro
  • Anti-replay duplo: Redis (TTL 5 min) + tabela de tokens usados — impossível pagar duas vezes com o mesmo QR
  • Depósitos via Multicaixa Express com webhook HMAC-SHA256; levantamentos com lock pessimista e retry automático em deadlock
  • KYC automatizado via QR do Bilhete de Identidade; convites de motoristas para frotas com notificação in-app e push
  • Sistema de pânico/GPS, gestão de frotas e motoristas, notificações multicanal (in-app, push FCM, SMS)
  • Integração WhatsApp Cloud API para comunicações operacionais

Arquitectura e segurança

  • ~180 endpoints REST documentados com Swagger; autenticação JWT + refresh silencioso (HttpOnly cookies)
  • Encriptação AES-256-GCM em campos sensíveis; padrão de idempotência para escritas críticas
  • Locks pessimistas com retry exponencial em SQLSTATE 40P01 (deadlock) e 55P03 (lock timeout)
  • Testes: Jest (unitários) + Playwright (E2E de UI e API); CI com GitHub Actions
